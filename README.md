# Coding Class Python Lab

A browser-based Python playground for students: write Python, press **Run**, and see the output. Supports `input()`, turtle drawing, line-by-line stepping, and stop points that show every variable.

**Use it here:** https://yufangsun.github.io/python-lab/

No install needed. Python runs in your browser via [Skulpt](https://skulpt.org/). Your code is saved in your own browser only.
